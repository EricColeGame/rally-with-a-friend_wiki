## Häufige RALLY WITH A FRIEND Serverfehler identifizieren

Bevor Sie Router-Einstellungen ändern oder Spieldateien neu installieren, müssen Sie den genauen Fehlerpunkt identifizieren. Die Multiplayer-Rennarchitektur stützt sich in der Regel entweder auf einen zentralen Relay-Hub oder auf ein hybrides Peer-to-Peer-(P2P)-Setup. Bei beiden Konfigurationen äußern sich Kommunikationsabbrüche in spezifischen Warnmeldungen auf dem Bildschirm oder Verhaltensfehlern.

Laut Community-Berichten treten bei Spielern unterschiedliche Symptome auf, je nachdem, ob das Problem auf der Client-Seite, dem Host-Rechner oder dem vorgelagerten Matchmaking-Relay liegt. Die folgende Übersicht der Symptome hilft dabei einzugrenzen, welche Fehlerbehebungsstufe zuerst angewendet werden sollte.

| Fehlersymptom | Wahrscheinliche Ursache | Hauptauswirkung | Sofort empfohlener Schritt |
| :--- | :--- | :--- | :--- |
| **„Verbindung zur Sitzung fehlgeschlagen“** | Timeout beim Matchmaking-Handshake | Beitritt zur Lobby nicht möglich | Lobby neu starten & Router-NAT neu initialisieren |
| **„Host nicht erreichbar (Code: 1004)“** | Strenge Firewall oder blockierter UDP-Port | Direkter Beitritt schlägt fehl | Ausführbare Datei in der OS-Firewall auf die Whitelist setzen |
| **Starkes Mikroruckeln & Ghosting** | Hoher Paketverlust / vertauschte Pakete | Desynchronisierte Fahrzeugphysik | Von WLAN auf kabelgebundenes Ethernet umsteigen |
| **„Authentifizierungs-Handshake abgelaufen“** | Plattform-Token-Desync (Steam/Konsole) | Rauswurf beim Laden der Etappe | Client neu authentifizieren & Plattform-Cache leeren |
| **Endloser Etappen-Ladebildschirm** | Stillstand bei der Asset-Synchronisation | Hängenbleiben im Übergangsbildschirm | Lokale Spieldateien auf Fehler überprüfen |

Wenn Ihr Fehler einen bestimmten numerischen Code enthält, notieren Sie sich diesen. Die überwiegende Mehrheit der Lobby-Abbrüche rührt jedoch von Socket-Erschöpfung, aggressiven Antivirenfiltern oder falsch konfiguriertem Network Address Translation (NAT) her und nicht von fehlenden Spieldateien.

## Schnelle Netzwerklösungen zur Wiederherstellung der Lobby-Verbindung

Wenn Sie keinen **RALLY WITH A FRIEND Server** erreichen können, lösen standardmäßige Triage-Protokolle die meisten vorübergehenden Routing-Engpässe. Internetanbieter (ISPs) wechseln häufig dynamische Routing-Pfade, was Ihren Datenverkehr gelegentlich über überlastete Netzwerkknoten leiten kann.

Führen Sie diese grundlegenden Anpassungen durch, bevor Sie sich an erweiterte Port-Konfigurationen wagen:

1. **Netzwerkgeräte neu starten:** Trennen Sie Ihr Modem und Ihren Router für volle 60 Sekunden vom Stromnetz, um den internen Cache-Speicher zu leeren und eine Erneuerung des IP-Lease zu erzwingen.
2. **Auf ein direktes Ethernet-Kabel wechseln:** WLAN verursacht Funkinterferenzen und schwankende Latenzspitzen, die Rallye-Physik-Engines nur schwer abfangen können.
3. **Lokalen DNS-Cache leeren:** Zwischengespeicherte Adressabfragen veralten häufig nach Spiel-Updates oder Client-Hotfixes.
4. **Bandbreitenfresser im Hintergrund deaktivieren:** Stellen Sie sicher, dass Cloud-Backups, Torrent-Clients und hochauflösende Videostreams in Ihrem lokalen Netzwerk pausiert sind.

```text
# So leeren Sie Ihren DNS-Cache unter Windows:
1. Drücken Sie die Windows-Taste + R, geben Sie „cmd“ ein und drücken Sie die Eingabetaste.
2. Geben Sie Folgendes ein: ipconfig /flushdns
3. Drücken Sie die Eingabetaste und starten Sie anschließend Ihren Spielclient neu.
```

Die folgende Tabelle zeigt die optimalen lokalen Netzwerkparameter, die für eine unterbrechungsfreie Verbindung zu jedem **RALLY WITH A FRIEND Server** erforderlich sind:

| Netzwerkparameter | Mindestanforderung | Idealwert für Rallye-Simulationen | Warum es wichtig ist |
| :--- | :--- | :--- | :--- |
| **Download-Geschwindigkeit** | 5 Mbit/s | 25+ Mbit/s | Schneller Download von Assets und Ghost-Daten |
| **Upload-Geschwindigkeit** | 1,5 Mbit/s | 10+ Mbit/s | Kontinuierliche Übertragung von Fahrzeugtelemetrie |
| **Ping / Latenz** | Unter 100 ms | Unter 45 ms | Verhindert Rubberbanding und Clipping |
| **Jitter** | Unter 15 ms | Unter 3 ms | Gewährleistet ein verlässliches Timing der Ansagen |
| **Paketverlust** | 0,0 % | 0,0 % | Verhindert plötzliches Teleportieren von Fahrzeugen |

## Desynchronisation und Latenzspitzen zwischen Host und Client beheben

Tandem-Rallyerennen erfordern eine präzise physikalische Abstimmung zwischen beiden Fahrern. Wenn Ihr Koop-Partner scheinbar von Klippen stürzt oder unkontrolliert über die Straße springt, liegt das meist an asymmetrischen Tick-Raten oder Paketpuffer-Überläufen zwischen Client und Host.

Die Erfahrung der Spieler zeigt, dass sich Desynchronisationen in der Regel verschlimmern, wenn ein Teilnehmer einen uneingeschränkten NAT-Typ nutzt, während der andere einen „Strikten“ (Strict) oder „Moderaten“ (Moderate) NAT-Typ hat. In diesem Szenario fällt es dem Spielserver schwer, eine kontinuierliche Peer-Erkennung aufrechtzuerhalten, was zu verzögerten Positionsdaten führt.

Um festzustellen, ob die Latenz von Ihrer eigenen Verbindung oder vom Host-Rechner ausgeht, vergleichen Sie die Ping-Werte im Spiel mit den standardmäßigen regionalen Serverwerten:

| Latenzbereich | Netzwerkerlebnis | Wahrscheinliche Ursache | Abhilfemaßnahme |
| :--- | :--- | :--- | :--- |
| **10 ms – 40 ms** | Knackige, reaktionsschnelle Eingaben; makellose Tandem-Läufe | Optimale Verbindung | Keine erforderlich |
| **45 ms – 85 ms** | Geringfügige, kosmetische Lags beim gegnerischen Fahrzeug | Weiter entfernter regionaler Server | Eine nähere Matchmaking-Region wählen |
| **90 ms – 150 ms** | Spürbare Eingabeverzögerung; verspätete Beifahrer-Ansagen | Ineffizientes ISP-Routing | Benutzerdefiniertes DNS oder saubere VPN-Route nutzen |
| **150+ ms / Paketverluste** | Starkes Rubberbanding; Fahrzeug-Desync | Lokale Funknetz-Überlastung oder ISP-Drosselung | Per Ethernet verbinden; ISP kontaktieren |

Wenn Sie die Sitzung hosten, fungiert Ihr System als maßgeblicher Physikserver. Sollte Ihre Hardware unter Frame-Einbrüchen oder Hintergrund-CPU-Drosselung leiden, kommt es bei Clients, die mit Ihrem **RALLY WITH A FRIEND Server** verbunden sind, unabhängig von deren eigener Internetgeschwindigkeit zu Rucklern.

## Firewall- und Portweiterleitungs-Grundlagen für Koop-Rennen

Strenge Firewalls des Betriebssystems und geschlossene Router-Ports sind der häufigste Grund, warum Freunde privaten Lobbys nicht beitreten können. Standardmäßig stufen Sicherheitssuiten eingehenden Peer-to-Peer-UDP-Verkehr als potenziell verdächtig ein und verwerfen Pakete stillschweigend, bevor die Game-Engine sie verarbeiten kann.

Um eine reibungslose Kommunikation mit dem **RALLY WITH A FRIEND Server** zu ermöglichen, stellen Sie sicher, dass die ausführbare Datei in Ihrer Sicherheitssoftware freigegeben ist, und ziehen Sie die Konfiguration von Portweiterleitungen in Ihrem Router-Dashboard in Betracht.

### Schritte zum Freigeben der ausführbaren Spieldatei

1. Öffnen Sie die Sicherheitseinstellungen Ihres Betriebssystems (z. B. Windows Defender Firewall).
2. Wählen Sie **Eine App oder ein Feature durch die Windows Defender Firewall zulassen**.
3. Klicken Sie auf **Einstellungen ändern** und wählen Sie dann **Andere App zulassen**.
4. Navigieren Sie zu Ihrem Spielinstallationsverzeichnis und wählen Sie die Haupt-`.exe`-Datei der Anwendung aus.
5. Aktivieren Sie die Kontrollkästchen für **Privat** und **Öffentlich** und klicken Sie auf **OK**.

### Empfohlene Portzuweisungen

Wenn die Freigabe in der Firewall die Verbindungs-Timeouts nicht behebt, leiten Sie die Standard-Netzwerkports weiter, die von modernen Koop-Renn-Frameworks genutzt werden:

| Portbereich | Protokoll | Netzwerkfunktion | Auswirkung bei Blockierung |
| :--- | :--- | :--- | :--- |
| **3074** | UDP / TCP | Matchmaking & Sitzungs-Handshake | Aktive Lobbys von Freunden sind nicht sichtbar |
| **27015 – 27030** | UDP | Steam/Plattform-Spieldatenverkehr | Verbindungsabbruch während der Etappenübergänge |
| **80, 443** | TCP | Web-Authentifizierung & Konto-Synchronisierung | Anmeldung bei Online-Profilen nicht möglich |
| **7777 – 7780** | UDP | Direkte Übertragung der Peer-Telemetrie | Schwere Desynchronisation und Paketverluste |

Weisen Sie Ihrem Gaming-PC oder Ihrer Konsole vor der Konfiguration von Portweiterleitungsregeln stets eine statische lokale IP-Adresse über die DHCP-Reservierungseinstellungen Ihres Routers zu.

## Erweiterte Fehlerbehebung: Integritätsprüfungen und Plattformdiagnose

Wenn die Netzwerkkonfiguration optimal ist und Sie dennoch keinem **RALLY WITH A FRIEND Server** beitreten können, liegt die Ursache möglicherweise an beschädigten lokalen Installationsdateien, veralteten Spielversionen oder beschädigten Download-Caches.

Beschädigte Etappendaten können zu Client-Abstürzen führen, sobald der Host ein Event lädt. Durch das Überprüfen Ihrer Installation wird sichergestellt, dass alle Teilnehmer identische Konfigurationsdateien und Assets verwenden. Wenn Sie auf dem PC über Steam spielen, finden Sie in der offiziellen [Steam Support-Dokumentation](https://help.steampowered.com/) Schritt-für-Schritt-Anleitungen zum Reparieren von Spielbibliotheken und Bereinigen hartnäckiger Download-Caches.

| Plattform | Überprüfungsmethode | Speicherort für Cache-Bereinigung | Häufig behobener Fehler |
| :--- | :--- | :--- | :--- |
| **PC (Steam)** | Rechtsklick auf Spiel > Eigenschaften > Installierte Dateien > Integrität überprüfen | Einstellungen > Downloads > Download-Cache leeren | Fehlende Texturdateien, Desync beim Laden der Etappe |
| **PC (Epic Games)** | Bibliothek > Klick auf „...“ auf Spielekachel > Verwalten > Überprüfen | AppData/Local/EpicGamesLauncher/Saved | Blockierte Matchmaking-Warteschlangen, Anmeldefehler |
| **Xbox Series X/S** | Spiel & Add-ons verwalten > Updates | Einstellungen > Geräte & Verbindungen > Blu-ray > Permanenter Speicher löschen | Wiederkehrende Fehlermeldungen „Host nicht erreichbar“ |
| **PlayStation 5** | Einstellungen > Speicher > Konsolenspeicher > Spiele und Apps | Datenbank im Sicherheitsmodus neu aufbauen | Beschädigte Speicherdaten verhindern Lobby-Beitritt |

Vergewissern Sie sich außerdem, dass Sie und Ihr Freund dieselbe Spielversion ausführen. Automatische Hintergrund-Updates schlagen manchmal fehl oder verzögern sich, sodass ein Spieler auf einem älteren Patch verbleibt, den die aktive Architektur des **RALLY WITH A FRIEND Servers** ablehnt.

## Best Practices für stabile Koop-Rennsessions

Um künftige Verbindungsabbrüche zu verhindern, sollten Sie vor längeren Rallye-Meisterschaften feste Netzwerkroutinen etablieren. Einige einfache Gewohnheiten stellen sicher, dass Ihre Lobbys stabil und reaktionsschnell bleiben:

- **Die beste Hardware als Host bestimmen:** Lassen Sie immer den Spieler mit der niedrigsten Basislatenz, der höchsten Upload-Bandbreite und der stärksten CPU die Koop-Sitzung hosten.
- **Clients vor langen Sessions neu starten:** Längere Spielzeiten können zu Speicherlecks oder Socket-Anhäufungen in lokalen Netzwerkadaptern führen. Ein kurzer Neustart des Clients leert diese Puffer.
- **VPN-Wechsel während des Spiels vermeiden:** Obwohl ein VPN gelegentlich schlechtes ISP-Routing umgehen kann, führt das Wechseln von Serverknoten bei laufendem Spiel zu sofortigen Sitzungsabbrüchen.
- **Etappen-Asset-Ladezeiten koordinieren:** Wenn ein Fahrer eine mechanische Festplatte verwendet, während der andere eine ultraschnelle NVMe-SSD nutzt, geben Sie der Lobby vor dem Start der Etappe ein paar zusätzliche Sekunden, um die Synchronisation zu bestätigen.

Indem Sie Netzwerkkonfigurationen, Firewall-Berechtigungen und Plattform-Einstellungen systematisch überprüfen, können Sie jede Hürde rund um den **RALLY WITH A FRIEND Server** meistern und ohne Unterbrechung zum kompetitiven Koop-Rennsport zurückkehren.

## Häufig gestellte Fragen

### Warum trennt sich die Verbindung zum RALLY WITH A FRIEND Server genau dann, wenn ein Rennen beginnt?
Dieses Problem tritt typischerweise aufgrund einer Asset-Abweichung oder eines MTU-Paketverlusts (Maximum Transmission Unit) auf. Beim Laden einer Etappe überträgt das Spiel plötzlich einen großen Schub an Umgebungs- und Physikdaten zwischen den Spielern. Wenn Ihr Router die Paketfragmentierung blockiert oder ein Spieler beschädigte Streckendateien hat, kommt es zu einem Timeout der Verbindung. Das Überprüfen der lokalen Dateien und das Aktivieren von Universal Plug and Play (UPnP) auf Ihrem Router behebt dieses Problem in der Regel.

### Beeinflusst der NAT-Typ meine Fähigkeit, der Lobby eines Freundes beizutreten?
Ja. Wenn sowohl Sie als auch Ihr Freund einen „Strikten“ (Typ 3) NAT-Typ haben, ist eine direkte Peer-to-Peer-Verbindung ohne dedizierten Relay-Server praktisch unmöglich. Streben Sie einen „Offenen“ (Typ 1) oder „Moderaten“ (Typ 2) NAT-Typ an, indem Sie UPnP aktivieren oder entsprechende Portweiterleitungsregeln im Administrationsbereich Ihres Routers einrichten.

### Kann Antivirensoftware von Drittanbietern Spiel-Lobbys blockieren?
Aggressive Echtzeit-Virenscanner halten Peer-to-Peer-UDP-Rennverkehr häufig fälschlicherweise für böswillige eingehende Angriffe. Deaktivieren Sie Sicherheitssuiten von Drittanbietern vorübergehend oder fügen Sie die ausführbare Datei und den Installationsordner des Spiels zur Whitelist Ihres Antivirenprogramms hinzu, um zu testen, ob die Software Serverpakete abfängt.

### Wie überprüfe ich, ob die offiziellen Server wegen Wartungsarbeiten offline sind?
Überprüfen Sie die offiziellen Social-Media-Kanäle des Entwicklers, den Community-Hub oder Plattform-Status-Dashboards (wie Steam oder Konsolen-Netzwerk-Tracker). Geplante Serverwartungen oder unerwartete Ausfälle verhindern vorübergehend, dass ein **RALLY WITH A FRIEND Server** Konten authentifiziert oder private Lobbys hostet.
